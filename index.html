The app shelf

Each app solves one clear problem. Open any of them in your browser and start using it.

OpenMusic

Music player · Web + Android

One mobile-first player for music across Chinese and independent sources. Search once, play instantly, build a library and explore regional charts, artist discographies and ready-made year packs.

  • Multi-source search
  • 15 languages
  • Background play
Open OpenMusic

RealUFO

UFO case archive · Web + API + MCP

A living archive of declassified UFO cases. Browse the timeline, query the API, or ask your AI assistant through the MCP server.

  • Case archive
  • REST API
  • MCP server
Open RealUFO

MoneyRate

Currency toolkit · Web

A fast converter for people who live across currencies. Compare fiat, crypto and commodities, follow charts, set alerts, plan a trip, check a quote or convert a whole list at once.

  • 30 languages
  • Rate alerts
  • Batch + trip tools
Open MoneyRate

洛書命理

Chinese fortune-telling · Web

Bazi and Ziwei chart casting with AI-assisted interpretation. Enter a birth moment, get both charts, TL;DR summaries and visual timelines of your decade luck.

  • Bazi + Ziwei
  • TL;DR summaries
  • Luck timelines
Open Numerology

OpenQ

Live Q&A · Web

A forum in a queue for events, teams and rooms. Open a Q, share the QR code, let people ask and upvote from their phones, then work through the best questions in present mode.

  • No signup to join
  • Host controls
  • Polls + export
Open OpenQ

ClipBin

Clipboard desk · Web

A compact home for the text and images you do not want to lose. Type, paste, drop, upload or save what is already on your clipboard, then bring it back in a tap.

  • Text + images
  • One-tap capture
  • Fast retrieval
Open ClipBin

ZhConvert

Script converter · Web

Paste text or drop a file to convert between Simplified and Traditional Chinese. Handles plain text, Markdown, subtitles (SRT/VTT/LRC/ASS) and JSON — dialogue only, timestamps untouched.

  • Simplified ⇆ Traditional
  • Subtitle-safe
  • File upload
Open ZhConvert

Holdr

Portfolio tracker · Web

A clear view of your holdings across manual entries and broker data. See allocation, cost basis, gains and performance history together, with multi-currency display and AI-assisted analysis.

  • Broker sync
  • Performance history
  • Multi-currency
Open Holdr
